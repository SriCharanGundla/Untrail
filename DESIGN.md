# Untrail interface

Native Android Views with bundled Manrope. Monochrome Light, Dark, and System appearance, saved in app preferences. System is the default. Light uses an off-white canvas and charcoal foreground; Dark reverses the hierarchy. No green accents.

Main: wordmark, settings action, editor with icon toolbar, conditional result/copy action, WhatsApp and Others sharing. Settings: separate Activity with a back arrow and platform back navigation, appearance selection, draft switch, concise info tooltip with an 18dp glyph and 48dp tap target, and conditional accessibility setup. The setup button/helper disappear when access is enabled and return if revoked.

48dp icon targets, 56dp action buttons, 18dp button corners, 16dp surfaces, native ripples/focus, reduced-motion-aware pressed feedback. Main draft/undo state survives recreation and appearance changes. No promotional sections or extra permissions.
